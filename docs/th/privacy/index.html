ความเป็นส่วนตัว

หน้านี้อธิบายสิ่งที่เว็บไซต์นี้ทำ โดยเขียนให้ตรงกับการทำงานจริงของเว็บไซต์ ไม่มากไปกว่านั้น

ผู้จัดทำเว็บไซต์นี้

เว็บไซต์นี้เป็นผลงานออกแบบตัวอย่างที่ไม่เป็นทางการ จัดทำโดย O2 Design Studio ไม่ได้จัดทำโดยโรงแรมแกรนด์ไดมอนด์สวีท และโรงแรมไม่ได้เป็นผู้รับผิดชอบเว็บไซต์นี้

ข้อมูลที่เว็บไซต์เก็บ

ไม่มีการเก็บข้อมูลใด ๆ ไม่มีบัญชีผู้ใช้ ไม่มีระบบวิเคราะห์การใช้งาน ไม่มีแท็กโฆษณา และไม่มีคุกกี้ เว็บไซต์นี้ไม่มีเซิร์ฟเวอร์ของตนเองที่รับข้อมูลที่คุณพิมพ์

ข้อมูลที่อยู่ในเบราว์เซอร์ของคุณ

เพื่อให้ตัวเลือกของคุณยังอยู่เมื่อเปลี่ยนหน้าหรือเปลี่ยนภาษา เว็บไซต์จะเก็บวันเข้าพัก จำนวนผู้ใหญ่ อายุของเด็กที่ระบุไว้ ห้องสวีทที่เปิดดูล่าสุด และตัวเลือกในการเปรียบเทียบ ไว้ในพื้นที่จัดเก็บชั่วคราวของเบราว์เซอร์ ข้อมูลเหล่านี้ไม่ถูกส่งออกจากอุปกรณ์ของคุณ และจะถูกลบเมื่อปิดแท็บ

หากคุณสลับภาษา เว็บไซต์จะจำภาษาที่เลือกไว้ในพื้นที่จัดเก็บของเบราว์เซอร์ เพื่อให้หน้าแรกของเว็บไซต์เปิดเป็นภาษาเดิมในครั้งถัดไป ข้อมูลนี้อยู่ในอุปกรณ์ของคุณจนกว่าคุณจะล้างข้อมูลเบราว์เซอร์

ข้อความที่พิมพ์ในตัวช่วยเรียบเรียงข้อความสอบถามจะไม่ถูกจัดเก็บ และอยู่บนหน้าเว็บเท่านั้นจนกว่าคุณจะออกจากหน้า

เมื่อคุณไปยังหน้าจอง

เมื่อเลือกตรวจสอบห้องว่าง หน้าจองทางการของโรงแรมจะเปิดขึ้นในแท็บใหม่ ลิงก์จะส่งจำนวนผู้ใหญ่ อายุของเด็กที่ระบุไว้ และหากเลือกวันที่ จะส่งวันเข้าพักและจำนวนคืนไปด้วย เพื่อให้หน้านั้นแสดงผลตามที่เลือก โดยไม่มีข้อมูลอื่นถูกส่งไป

หลังจากนั้น โรงแรมและผู้ให้บริการระบบจองจะดูแลข้อมูลของคุณตามนโยบายของตนเอง

เว็บไซต์อื่นที่มีลิงก์ไปถึง

ลิงก์ไปยังแผนที่ หน้าโซเชียลของโรงแรม และเว็บไซต์ของโรงแรม จะเปิดบริการเหล่านั้นซึ่งมีนโยบายของตนเอง แผนที่ในเว็บไซต์นี้เป็นภาพนิ่งและไม่ได้โหลดข้อมูลจากผู้ให้บริการแผนที่ ส่วนแบบอักษรและภาพถ่ายให้บริการจากเว็บไซต์นี้เอง

ผู้ให้บริการโฮสต์เว็บไซต์

เว็บไซต์ตัวอย่างนี้โฮสต์บน GitHub Pages เช่นเดียวกับผู้ให้บริการโฮสต์ทั่วไป GitHub อาจบันทึกข้อมูลทางเทคนิค เช่น หมายเลข IP เมื่อเบราว์เซอร์ของคุณเรียกดูหน้าเว็บ O2 Design Studio ไม่ได้รับและไม่ได้ใช้ข้อมูลดังกล่าว
