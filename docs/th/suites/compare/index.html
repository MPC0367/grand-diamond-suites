  2. จูเนียร์สวีท 45 ตร.ม.
  3. แฟมิลี่สวีท 45 ตร.ม.
  4. ดีลักซ์สวีท 90 ตร.ม.
  5. เอ็กเซ็กคูทีฟสวีท 120 ตร.ม.
